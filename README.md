## Project Description
A console-driven JavaScript implementation mastering core language mechanics, featuring a multi-operator mathematical calculator and an object-oriented student grade management tracking system. Built to enforce strict syntax discipline, higher-order array transformations, and robust data structuring without DOM interference.

## Technologies Used
- JavaScript (ES6+)
- HTML5 (Console Runner)
- Git & GitHub Version Control

## Features
- **Console Calculator:** Handles addition, subtraction, multiplication, division, modulus, and exponentiation with explicit zero-division safeguards.
- **Student Grade Tracker:** Object-based management system supporting student record additions, individual and subject-specific averages, top-performer identification, and automated report card generation.
- **Advanced Array Methods:** Leverages `map`, `filter`, `reduce`, `find`, `some`, and `every` for declarative data processing.
- **Clean Environment Configuration:** Fully isolated workspace with strict `.gitignore` rules preventing unnecessary artifact commits.

## Lessons Learned
JavaScript exposes sloppy logic instantly. Transitioning from markup to programmatic control required breaking reliance on visual cues and trusting console execution, strict variable scoping (let vs const), and clean functional paradigms.

## Challenges Faced
Handling nested object lookups and edge-case zero-division states inside custom reduction functions required rigorous test-case validation to prevent runtime reference errors.
